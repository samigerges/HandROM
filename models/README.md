# MediaPipe model

`hand_landmarker.task` is the official MediaPipe Hand Landmarker model bundle. The application expects it at:

```text
models/hand_landmarker.task
```

Official latest-model URL:

```text
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
```

The model is distributed by the MediaPipe project; review the upstream model card and license before redistribution.
